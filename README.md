# Music Finder Bot

Telegram-бот для поиска музыки по названию, исполнителю или фрагменту текста.

## Запуск

Нужна переменная окружения BOT_TOKEN с токеном Telegram-бота.

Бот использует LRCLIB для поиска и показывает ссылки на YouTube, Spotify и Apple Music.

Прямое скачивание защищённых авторским правом аудиофайлов не реализовано.
